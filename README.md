a one-paragraph elevator pitch describing your project;
- MealDeal is a website where people can track meals, nutrition facts, create
  recipes and create grocery lists. Users can create meal preparations for Monday-Friday
  and they can create meal preparations for breakfast, lunch, and dinner. Users can
  browse for recipes without having an account. Creating an account can allow
  users to save recipes and everything else. 

instructions on installing your project;
- Download and Install Node.js
- Install MYSQL and MYSQL workbench
- Clone or download the MealDeal project from GitHub.
- Open the project folder in Visual Studio Code.
- Open the terminal in Visual Studio Code.
- Install the required dependencies by running npm install
- Then create a SQL folder and add the database connection
- DB_HOST=localhost
- DB_USER=root
- DB_PASSWORD=your_password
- DB_NAME=mealdeal
- DB_PORT=3306
